# Module 01 — Agentic RAG

Short description
- Build a Retrieval-Augmented Generation (RAG) pipeline from scratch, then convert it into an agent that decides when and what to search.

Learning objectives
- Implement a simple search index and tokenizer-backed retrieval.
- Assemble search results into prompts and call an LLM to answer queries.
- Chunk long documents to improve retrieval precision.
- Turn a fixed RAG pipeline into an agent using function-calling/tool interfaces.

Structure
- `class_materials/` — lesson pages, example code, and videos. Start here for lessons and notebooks.
- `homework01/` — assignment, checks, and submission link.

Estimated effort
- 5–10 hours (depending on background). Follow the lessons in order.

How to use this module
1. Read the lessons in `class_materials/README.md` in order.
2. Work through the example code in `class_materials/code/`.
3. Complete the homework in `homework01/homework.md` and submit according to the instructions there.

Support & community
- Share progress in your preferred social channels (see learning-in-public examples in the homework).
- If you run a cohort, use weekly issue templates (or the repo's PRs) to collect submissions and feedback.
