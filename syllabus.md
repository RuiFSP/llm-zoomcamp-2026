# LLM Zoomcamp 2026 — Syllabus (local study copy)

This repo mirrors a weekly cohort-style study rhythm: each module is developed week-by-week. Use this file as the course schedule and quick reference.

Course cadence
- Weekly release: add `class_materials/` content and `homeworkNN/` for the week.
- Expected effort: 5–10 hours/week.
- Submission: PR to your fork or zip + LMS link; use `homeworkNN/README.md` to describe run instructions.

Planned modules (initial roadmap)
1. 01-agentic-rag — RAG pipeline and agentic loop (present)
2. 02-vector-search — embeddings, FAISS/PGVector, hybrid search
3. 03-orchestration — orchestration patterns and Kestra
4. 04-evaluation — retrieval & answer evaluation (offline/online)
5. 05-monitoring — metrics, dashboards, feedback loops
6. 06-best-practices — LangChain patterns, reranking, production tips
7. 07-project-example — end-to-end example project
8. Capstone — `project.md` with capstone guidelines and rubric

How to follow this repo
- Read `01-agentic-rag/class_materials/README.md` to start Module 1.
- Watch for weekly PRs or add your own folders following `MODULE_TEMPLATE.md`.
- Use `.github/ISSUE_TEMPLATE/weekly-review.md` to post weekly progress notes.
